# Уютные привычки

Личное веб-приложение для iPhone: привычки питания, тренировок и медитации в игровой форме
(опыт, уровни, серии, монеты, мини-игры). Открывается в Safari и ставится на экран «Домой».

## Установка на iPhone

1. Открой https://suimak.github.io/Habit/ в Safari.
2. Нажми «Поделиться» → «На экран „Домой“».
3. Запускай с иконки — приложение работает и без интернета.

Прогресс хранится только на телефоне. Время от времени делай копию: «Дом» → «Настройки» → «Сохранить копию».

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm test         # автотесты игровой логики
npm run build    # сборка в dist/
```

- `src/core` — игровая логика без интерфейса (XP, уровни, серии, щиты, монеты, жизни, шкалы).
- `src/screens`, `src/components` — экраны и элементы интерфейса.
- Данные хранятся только на устройстве (localStorage).

Публикация: каждый push в `main` проверяется и выкладывается на GitHub Pages
(`.github/workflows/deploy.yml`).
